Setup do Banco de Dados

1. Criar Banco de Dados

Clique no botão abaixo para criar o banco de dados automaticamente.

Ou faça manualmente:

  1. Acesse phpMyAdmin
  2. Clique em "Importar"
  3. Selecione o arquivo comanda_online.sql
  4. Clique em "Executar"

2. Verificar Conexão

Testar se a API consegue conectar ao banco de dados.

3. Configurar Empresa

Configure os dados iniciais da empresa.

Após configurar o banco de dados, todas as informações serão salvas no MySQL.
